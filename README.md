# Potato Vibes (agentic engineering test project)

A game where you launch a potato as far as possible!

[Play online](https://l1ghty.github.io/potato-vibes/)

## How to Play

1. **Click** to set power
2. **Click again** to set angle  
3. **Hold mouse/touch** during flight to glide
4. Hit **blue jump pads** for a boost!

## Features

- Power and angle selection
- Gliding mechanic for extended distance
- Jump pads for speed boosts
- High score tracking
- Volume controls
- Fullscreen mode
- Pause functionality

## Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Set power/angle | Click | Tap |
| Glide | Hold mouse button | Touch & hold |
| Pause | Click pause button | Tap pause button |
| Restart | Click restart button | Tap restart button |

## Technologies

- Vanilla JavaScript
- HTML5 Canvas
- CSS3
